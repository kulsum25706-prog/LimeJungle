# 🌿 LimeJungle

A simple and clean website built using **HTML5 and CSS3**.  
LimeJungle is a modern web template project featuring navigation, blog content, sidebar sections, image gallery, sponsors and contact information.

## 🚀 Live Demo

👉 **[View LimeJungle Live Demo](https://kulsum25706-prog.github.io/LimeJungle/)**

## 📌 Features

- 🏠 Home page
- 📰 Blog section
- 📞 Contact page
- ℹ️ About Us page
- 🆘 Support page
- 🔎 Search section
- 🖼️ Image gallery
- 📋 Sidebar menu
- 📱 Clean website layout
- 🎨 Custom CSS styling

## 🛠️ Technologies Used

- HTML5
- CSS3
